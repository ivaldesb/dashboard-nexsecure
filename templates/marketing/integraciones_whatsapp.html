Opciones de Integración

Evolution API Recomendado

API open-source para WhatsApp Business con múltiples instancias y alta capacidad.

  • Requerimientos: Servidor con Evolution API instalado
  • Ventajas: Gratuita, open-source, muy flexible
  • Ideal para: Envío masivo, campañas, automatización

API Oficial de WhatsApp Business

Integración directa con la API oficial de WhatsApp Business (requiere cuenta verificada).

  • Requerimientos: Cuenta de WhatsApp Business verificada
  • Ventajas: Totalmente oficial, alta capacidad
  • Costo: Puede requerir suscripción

Servicio de Terceros (Twilio, etc.)

Integración a través de servicios que facilitan el envío de mensajes.

  • Requerimientos: Cuenta en el servicio
  • Ventajas: Fácil de configurar, más flexible
  • Costo: Varía según el servicio
Ejemplo: http://localhost:8080 o https://api.evolutionapi.com
