## 📖 Cómo Usar

### 1. Importar el archivo CSS
```html
<link href="{{ url_for('static', filename='css/color-palette.css') }}" rel="stylesheet">
```

### 2. Usar variables CSS
```css
.mi-elemento {
    background-color: var(--primary);
    color: var(--text-on-primary);
    border: 1px solid var(--primary-200);
    box-shadow: var(--shadow-primary);
}
```

### 3. Usar clases utilitarias
```html
<div class="bg-primary text-white">Contenido</div>
<div class="gradient-primary text-white">Gradiente</div>
<div class="shadow-primary">Sombra</div>
```

### 4. Ver vista previa
Visita: `/color-palette` en tu aplicación para ver una vista previa visual de todos los colores.

## 🎯 Recomendaciones de Uso

1. **Color Principal (#0066FF)**: Usar para botones principales, enlaces, elementos destacados
2. **Variaciones 50-200**: Para fondos suaves y hover sutiles
3. **Variaciones 600-900**: Para hover y estados activos
4. **Colores de Acento**: Usar para elementos secundarios que necesiten destacar
5. **Neutros**: Para texto, bordes, fondos que no deben competir con el color principal
6. **Gradientes**: Para hero sections, botones especiales, fondos llamativos
7. **Sombras**: Usar con moderación, especialmente `--shadow-primary` para elementos importantes
